# Residential Electricity Demand in Vietnam: QAIDS with Time-of-Use Pricing

> **Status: working project, not peer reviewed.** Results are preliminary and are not summarised here; see the manuscripts in the repository.

Consumer Behaviour Analysis course project (UEH). Estimates a household electricity demand system with a Quadratic Almost Ideal Demand System (QAIDS) extended with time-of-use tariff variables, using VHLSS 2022. Contents: Stata do-files and logs, LaTeX source (`02. code latex`), figures (`04. picture`), draft and submitted versions (English and Vietnamese).

**Author:** Truong Nhat Duy (Truong Nhat Duy), University of Economics Ho Chi Minh City (UEH).

**Period:** Oct 2025 - Dec 2025 (Consumer Behaviour Analysis course, UEH). Dates are taken from file timestamps.

## Data availability

VHLSS 2022 microdata and derived `.dta` files are excluded (data-use terms of the General Statistics Office). Reference literature is not redistributed. Replicating the analysis requires obtaining the original data from the providers.
